# 🎯 ゲームパラメータ（一元管理）

このドキュメントでは、ゲーム全体で使用される数値パラメータを一元管理します。
各ドキュメントから参照される、唯一の信頼できる情報源（Single Source of Truth）です。

---

## 時間設定

| パラメータ         | 値     | 説明                               |
| ------------------ | ------ | ---------------------------------- |
| **ゲーム時間**     | 30 秒  | プレイ可能な制限時間               |
| **カウントダウン** | 3 秒   | 3, 2, 1 のカウントダウン時間       |
| **Start! 表示**    | 0.5 秒 | "Start!" の表示時間                |
| **合計開始演出**   | 3.5 秒 | カウントダウンから Start! まで合計 |

---

## 高度設定

| パラメータ                 | 値      | 説明                                     |
| -------------------------- | ------- | ---------------------------------------- |
| **星（ゴール）の高度**     | 800m    | 勝利条件となるゴール地点                 |
| **宇宙飛行士の登場高度**   | 800m 以上 | 大気圏外に到達した時の演出要素           |
| **低高度範囲**             | 0-200m  | 電線、カラス、凧揚げなどが配置される高度 |
| **中高度範囲**             | 200-500m | 雲（松・竹）が配置される高度             |
| **高高度範囲**             | 500m 以上 | 雲（梅）、隕石、流れ星が配置される高度   |

---

## ダメージ設定

| パラメータ               | 値     | 説明                                 |
| ------------------------ | ------ | ------------------------------------ |
| **雷ヒット時の落下距離** | -30m   | 雷に当たった時の高度ペナルティ       |
| **風船復活時間**         | 2.0 秒 | 風船が割れてから復活するまでの時間   |
| **隕石ヒット時の落下距離** | -50m   | 隕石に当たった時の高度ペナルティ     |
| **カラスの押し下げ距離** | -20m   | カラスに妨害された時の高度ペナルティ |

---

## 雲のパラメータ

| パラメータ             | 松（雷ギミック） | 竹（速度閾値） | 梅（通過不可） |
| ---------------------- | ---------------- | -------------- | -------------- |
| 通り抜け速度閾値       | なし             | 4.0 m/s（仮）  | ∞（不可）      |
| 雷の発生頻度           | 3〜5 秒          | なし           | なし           |
| 雷ダメージ（落下距離） | -30m             | なし           | なし           |
| 風船復活時間           | 2.0 秒           | なし           | なし           |

## 物理パラメータ（仮）

以下のパラメータは調整が必要です。実装時に最適値を決定します。

| パラメータ       | 値  | 説明                         |
| ---------------- | --- | ---------------------------- |
| **重力**         | TBD | SpriteKit の重力設定         |
| **上昇力係数**   | TBD | 息の強さから上昇力への変換係数 |
| **空気抵抗係数** | TBD | 速度に応じた抵抗             |
| **子供の質量**   | 10 kg（仮） | 物理演算用の質量             |

---

## 通信設定

| パラメータ       | 値                | 説明                             |
| ---------------- | ----------------- | -------------------------------- |
| **更新周期**     | 30Hz (33ms 間隔)  | 息の強さの送信頻度               |
| **通信遅延目標** | < 50ms            | ネットワーク遅延の目標値         |
| **serviceType** | onlylonelyp2p    | MultipeerKit が使用する Bonjour サービス名 |

---

## 画面設定

| パラメータ             | 値      | 説明                           |
| ---------------------- | ------- | ------------------------------ |
| **フレームレート**     | 60fps   | 画面描画のフレームレート       |
| **リザルト表示時間**   | 5 秒    | リザルト画面の最小表示時間     |
| **プレイヤー名最大文字数** | 10 文字 | プレイヤー名入力の制限         |

## 参照方法

他のドキュメントからこのファイルを参照する場合は、以下のように記載してください：

```markdown
ゲーム時間は **30秒** です。詳細は [ゲームパラメータ](./game-parameters.md#時間設定) を参照。
```

または

```markdown
雷ヒット時の落下距離など、数値パラメータは [ゲームパラメータ](./game-parameters.md) で一元管理しています。
```
