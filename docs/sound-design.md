### 7. 雲・雷の効果音

- 雲に衝突: ボフッという柔らかい衝突音
- 松の雲に衝突: ボフッという柔らかい衝突音
- 竹の雲を通過: シュッという風切り音
- 梅の雲に跳ね返る: ボンッという硬めの衝突音
- 雷が落ちる: バリバリという雷鳴
- 雷に当たる: ビリビリッという電撃音 + 風船が割れる音
- 風船再生成: ポンッという軽い音
- 虹色の綿雲発生: パステル調のベルサウンド + ふわふわした綿の降下音
- シャボン玉発射: 「ポワン」とした泡が膨らむ音、割れる時は高めの「パチン」

### 8. キャラクター同士の衝突音

- **キャラクター衝突**: ポンッという軽い衝突音（風船同士がぶつかる音）
- 戦略的な妨害プレイ時に発生
- ダメージはないが、プレイヤーに衝突を知らせる重要な音

### 9. 障害物衝突時のフィードバック音

各障害物ごとに固有の衝突音を設定し、プレイヤーに明確なフィードバックを提供:

| 障害物     | 効果音                                                   | 特徴                                   |
| ---------- | -------------------------------------------------------- | -------------------------------------- |
| 電線       | ビヨーン（バネの音）+ ビリビリ（微弱な電気音）           | 引っかかった感じを表現                 |
| カラス     | カーカー（鳴き声）+ バサバサ（羽ばたき音）               | 生き物感を強調                         |
| 凧揚げ     | ヒュルル（風切り音）+ コツッ（軽い衝突音）               | 軽さと風を感じさせる                   |
| 雲（松）   | ボフッ（柔らかい衝突音）+ ゴロゴロ（遠雷）               | 雷の予兆を含む                         |
| 雲（竹）   | シュッ（風切り音）+ ボソッ（通過音）                     | 通過できる感じを表現                   |
| 雲（梅）   | ボンッ（硬い衝突音）+ ドォーン（重低音の反響）           | 硬さと重さを強調                       |
| ロケット   | シュー（噴射音）+ ヒュン（加速音）                       | 勢いと推進力を表現                     |
| 流れ星     | キラキラ（軽い音）+ シャラーン（風鈴のような高音）       | 幻想的で軽やかな印象                   |
| 隕石       | ドカーン（爆発音）+ ゴゴゴ（重低音）                     | 衝撃の大きさを強調                     |
| 虹色の綿菓子雲 | キラキラしたベル音 + 綿が降る「ふわっ」音               | 優しいけれど妨害であることを伝える     |
| シャボン玉     | ポワン（発射）+ パチン（命中時）                        | 当たりの瞬間の驚きを演出               |

### 10. 衝突時の追加オーディオフィードバック

#### 衝突の強度に応じた音量変化

- **弱い衝突**（雲（竹）、流れ星）: 音量 50%、軽めの音
- **中程度の衝突**（電線、カラス、凧揚げ、雲（松））: 音量 75%、標準の音
- **強い衝突**（雲（梅）、隕石）: 音量 100%、重厚な音 + 低音強調

#### 空間オーディオ（3D サウンド）

- 衝突位置（左右）に応じてステレオパンニング
- iPad では左右のプレイヤーエリアで音の定位を変える
- iPhone ではヘッドフォン使用時に空間オーディオを活用（オプション）

#### ハプティクスフィードバック（iPhone のみ）

- 衝突時に振動フィードバック
- 衝突の強度に応じて振動パターンを変化:
  - **弱い衝突**: `.light` タップ
  - **中程度の衝突**: `.medium` タップ
  - **強い衝突**: `.heavy` インパクト
