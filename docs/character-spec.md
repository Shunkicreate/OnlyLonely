## 子供と風船の関係

### 通常時

```
    🎈  ← 風船（上昇力の源）
    ｜
   👦  ← 子供（持っている）
```

- 子供が風船を掴んでいる
- 風船の浮力で上昇
- 息を吹くと風船が膨らんで上昇力アップ

### 風船が割れたとき

#### 最小要件（MVP）

```
    💥  ← 風船が割れる
    ｜
   👦  ← ダメージ演出
   ✨   （透明度チカチカ、少し下降）
```

| 項目     | 内容                                             |
| -------- | ------------------------------------------------ |
| **演出** | 子供の透明度を正弦波でチカチカさせる（無敵時間） |
| **効果** | 少し下降する（例: -30m）                         |
| **時間** | 2 秒程度                                         |
| **状態** | 無敵時間中は他のダメージを受けない               |
| **風船** | 透明度が戻ると同時に風船も復活                   |

#### 将来的な実装（理想）

```
    💥  ← 風船が割れる
   👦↓ ← 子供が落下

   (1秒後)

    🎈  ← 新しい風船が出現
    ｜
   👦  ← 子供がキャッチ
```

- 風船が割れると子供が一時的に落下
- 新しい風船が降ってくる演出
- 子供がキャッチして再開

## ダメージシステム

### ダメージを受ける要素

| 要素                 | ダメージ内容       | 風船の状態 |
| -------------------- | ------------------ | ---------- |
| 雷                   | 風船が割れる       | 破裂       |
| 隕石                 | 大きく下降（-50m） | 維持       |
| カラス               | 小さく下降（-20m） | 維持       |
| 虹色の綿菓子雲       | 綿菓子の雨で下降（-10m） | 維持   |
| シャボン玉           | 怯み + 軽い下降（-5m） | 維持   |
| **キャラクター衝突** | **跳ね返る**       | **維持**   |

### ダメージ処理フロー

```swift
// 雷に当たった場合（MVP実装）
func onLightningHit() {
    // 1. 風船を非表示
    balloon.isHidden = true

    // 2. ダメージ演出開始
    startDamageAnimation()

    // 3. 少し下降
    currentAltitude -= 30

    // 4. 2秒後に復活
    DispatchQueue.main.asyncAfter(deadline: .now() + 2.0) {
        balloon.isHidden = false
        stopDamageAnimation()
    }
}

// ダメージ演出
func startDamageAnimation() {
    // 透明度を正弦波でチカチカ
    let animation = CABasicAnimation(keyPath: "opacity")
    animation.fromValue = 1.0
    animation.toValue = 0.3
    animation.duration = 0.2
    animation.autoreverses = true
    animation.repeatCount = 10 // 2秒間（0.2秒 × 10回 × 2往復）
    character.layer.add(animation, forKey: "damage")
}
```

## キャラクター同士の衝突判定

### 基本仕様

iPad の画面は**左右 2 分割**で、それぞれのプレイヤーエリアが表示されます。  
しかし、**物理的には同じ空間を共有**しており、キャラクター同士が衝突することがあります。

### 衝突時の挙動

```
画面左側（Player A）      画面右側（Player B）
┌─────────────┐     ┌─────────────┐
│             │     │             │
│   ⭐       │     │       ⭐   │
│             │     │             │
│   🎈       │     │       🎈   │
│   👦 ←──衝突──→ 👦   │
│             │     │             │
│             │     │             │
└─────────────┘     └─────────────┘
```

| 項目         | 内容                                       |
| ------------ | ------------------------------------------ |
| **発生条件** | 両プレイヤーが同じ高度で近い位置にいる時   |
| **物理挙動** | 互いに跳ね返る（反発力）                   |
| **効果**     | 横方向に少し押し出される                   |
| **サウンド** | 「ポンッ」という軽い衝突音                 |
| **ダメージ** | なし（風船は割れない）                     |
| **戦略性**   | 相手の進路を妨害したり、押し出したりできる |

### 衝突判定の詳細

```swift
// キャラクター同士の衝突判定
func checkCharacterCollision(playerA: SKNode, playerB: SKNode) {
    let distance = hypot(
        playerA.position.x - playerB.position.x,
        playerA.position.y - playerB.position.y
    )

    let collisionRadius = 64.0 // 2つの衝突半径の合計

    if distance < collisionRadius {
        // 衝突！跳ね返る
        applyRepulsionForce(playerA: playerA, playerB: playerB)
    }
}

// 反発力を適用
func applyRepulsionForce(playerA: SKNode, playerB: SKNode) {
    let dx = playerA.position.x - playerB.position.x
    let dy = playerA.position.y - playerB.position.y
    let distance = hypot(dx, dy)

    // 正規化された方向ベクトル
    let nx = dx / distance
    let ny = dy / distance

    // 反発力を加える
    let repulsionForce: CGFloat = 100.0
    playerA.physicsBody?.applyImpulse(CGVector(dx: nx * repulsionForce, dy: ny * repulsionForce))
    playerB.physicsBody?.applyImpulse(CGVector(dx: -nx * repulsionForce, dy: -ny * repulsionForce))
}
```

### 画面表示の仕様

#### iPad の画面分割

```
┌──────────────────────────────────────────┐
│                                          │
│  Player A エリア    │   Player B エリア  │
│                     │                    │
│      ⭐ (800m)     │     ⭐ (800m)      │
│                     │                    │
│      🎈            │            🎈      │
│      👦 (350m)     │     (280m) 👦      │
│                     │                    │
│  ☁️  ☁️  ☁️       │      ☁️  ☁️  ☁️   │
│                     │                    │
│  電線 ━━━━━━━      │      ━━━━━━━ 電線  │
│                     │                    │
│  地面 🏠 🌳        │        🌳 🏠 地面  │
└──────────────────────────────────────────┘
```

- **左半分**: Player A の視点
- **右半分**: Player B の視点
- **中央の線**: 画面分割ライン（薄い線 or なし）
- **同じ空間**: 物理的には同じ高度空間を共有
- **衝突可能**: キャラクター同士が接近すると衝突判定が発生

### 戦略的な意味

1. **妨害プレイ**

   - 相手の進路に割り込んで押し出す
   - 雲や障害物に向かって押し込む

2. **駆け引き**

   - わざと接近して相手のリズムを崩す
   - 衝突を避けるために左右に移動する必要がある

3. **リスク＆リターン**
   - 妨害すると自分も跳ね返される
   - タイミングを見極める必要がある

## ゴール到達演出

### 子供の動き

```
   ⭐  ← 星（ゴール）
   ／＼
  👦🎈 ← 到達！
  ＼／
   ✨  ← キラキラエフェクト
```

| 項目           | 内容                                     |
| -------------- | ---------------------------------------- |
| **タイミング** | 子供が星に接触した瞬間                   |
| **演出**       | 子供が喜ぶポーズ（手を上げる、ジャンプ） |
| **エフェクト** | Confetti（紙吹雪）が画面全体に広がる     |
| **サウンド**   | 勝利ファンファーレ + 拍手                |
| **時間**       | 3 秒程度                                 |

### Confetti 仕様

- SwiftUI の `confettiCannon` または `CAEmitterLayer`
- カラフルな紙吹雪が舞う
- 星から放射状に広がる
