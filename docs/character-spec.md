# 👦 キャラクター仕様書

## 概要

風船を持った子供が、星を目指して空を駆け上がるゲーム。  
子供と風船の関係性、アニメーション、ダメージ処理などを定義します。

## 子供と風船の関係

### 通常時

```
    🎈  ← 風船（上昇力の源）
    ｜
   👦  ← 子供（持っている）
```

- 子供が風船を掴んでいる
- 風船の浮力で上昇
- 息を吹くと風船が膨らんで上昇力アップ

### 風船が割れたとき

#### 最小要件（MVP）

```
    💥  ← 風船が割れる
    ｜
   👦  ← ダメージ演出
   ✨   （透明度チカチカ、少し下降）
```

| 項目     | 内容                                             |
| -------- | ------------------------------------------------ |
| **演出** | 子供の透明度を正弦波でチカチカさせる（無敵時間） |
| **効果** | 少し下降する（例: -30m）                         |
| **時間** | 2 秒程度                                         |
| **状態** | 無敵時間中は他のダメージを受けない               |
| **風船** | 透明度が戻ると同時に風船も復活                   |

#### 将来的な実装（理想）

```
    💥  ← 風船が割れる
   👦↓ ← 子供が落下

   (1秒後)

    🎈  ← 新しい風船が出現
    ｜
   👦  ← 子供がキャッチ
```

- 風船が割れると子供が一時的に落下
- 新しい風船が降ってくる演出
- 子供がキャッチして再開

## ダメージシステム

### ダメージを受ける要素

| 要素   | ダメージ内容       | 風船の状態 |
| ------ | ------------------ | ---------- |
| 雷     | 風船が割れる       | 破裂       |
| 隕石   | 大きく下降（-50m） | 維持       |
| カラス | 小さく下降（-20m） | 維持       |

### ダメージ処理フロー

```swift
// 雷に当たった場合（MVP実装）
func onLightningHit() {
    // 1. 風船を非表示
    balloon.isHidden = true

    // 2. ダメージ演出開始
    startDamageAnimation()

    // 3. 少し下降
    currentAltitude -= 30

    // 4. 2秒後に復活
    DispatchQueue.main.asyncAfter(deadline: .now() + 2.0) {
        balloon.isHidden = false
        stopDamageAnimation()
    }
}

// ダメージ演出
func startDamageAnimation() {
    // 透明度を正弦波でチカチカ
    let animation = CABasicAnimation(keyPath: "opacity")
    animation.fromValue = 1.0
    animation.toValue = 0.3
    animation.duration = 0.2
    animation.autoreverses = true
    animation.repeatCount = 10 // 2秒間（0.2秒 × 10回 × 2往復）
    character.layer.add(animation, forKey: "damage")
}
```

## ゴール到達演出

### 子供の動き

```
   ⭐  ← 星（ゴール）
   ／＼
  👦🎈 ← 到達！
  ＼／
   ✨  ← キラキラエフェクト
```

| 項目           | 内容                                     |
| -------------- | ---------------------------------------- |
| **タイミング** | 子供が星に接触した瞬間                   |
| **演出**       | 子供が喜ぶポーズ（手を上げる、ジャンプ） |
| **エフェクト** | Confetti（紙吹雪）が画面全体に広がる     |
| **サウンド**   | 勝利ファンファーレ + 拍手                |
| **時間**       | 3 秒程度                                 |

### Confetti 仕様

- SwiftUI の `confettiCannon` または `CAEmitterLayer`
- カラフルな紙吹雪が舞う
- 星から放射状に広がる

## 実装メモ

### 使用技術

- **SpriteKit**: 子供と風船の描画・物理演算
- **SKSpriteNode**: 子供と風船のノード
- **CABasicAnimation**: ダメージ演出の透明度アニメーション

### ファイル構成

```
Assets/
  Characters/
    child_red.png       # Player A の子供
    child_blue.png      # Player B の子供
    balloon_red.png     # Player A の風船
    balloon_blue.png    # Player B の風船
```

### 最小要件の画像仕様

- 子供: シンプルな 2D イラスト（棒人間でも可）
- 風船: 丸い風船の画像
- 透過 PNG 形式
- サイズ: 64x64px または 128x128px
