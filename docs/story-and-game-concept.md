# 📖 ストーリー・ゲームコンセプト

## タイトル

**OnlyLonely（オンリーロンリー）**

---

## キャッチコピー

> 「息で飛ばす、ふたりの風船」  
> 空には、誰もいない。  
> でも、誰かと同じ空を見上げている。

---

## ストーリー

```
遠くの星に、大切な誰かがいる。
会いたくて、届けたくて、
必死に風船を掴んで空を飛ぶ。

でも、同じように星を目指す誰かがいる。
ふたりとも、「OnlyLonely」じゃない。

息を吹きかけるたびに、風船が膨らみ、
少しずつ、少しずつ、空を登っていく。

電線に引っかかり、
カラスに邪魔され、
雷に打たれても、

それでも、風船を離さない。

先に星に辿り着くのは、誰だろう。
```

---

## ゲームコンセプト

### 核となる体験

1. **息を吹く身体性**

   - リアルに息を吹いて操作する
   - 身体的な没入感
   - 疲労感も含めたリアリティ

2. **競争と共感**

   - 相手と競い合う緊張感
   - でも、同じ空を飛ぶ仲間でもある
   - 切なさと温かさの共存

3. **シンプルだけど奥深い**

   - ルールは簡単（息を吹いて星を目指す）
   - 障害物の回避や息の配分で戦略性
   - 30 秒という短時間で決着

4. **カジュアルな対戦**
   - 1 ゲーム 30 秒
   - すぐに決着がつく
   - 気軽に何度でもプレイできる

---

## ゲームの目的

### プレイヤーの目標

**風船を持った子供を操作して、先に星（ゴール）に到達させる**

- 息を吹いて風船を膨らませ、上昇
- 障害物を避けながら上を目指す
- 30 秒以内に星に到達できれば勝利

### ゲームの終了条件

| 条件                          | 結果         |
| ----------------------------- | ------------ |
| **先に星に到達した**          | 即座に勝利！ |
| **30 秒以内に誰も到達しない** | 引き分け     |

---

## 勝利条件の詳細

### パターン 1: ゴール到達で勝利

```
   ⭐  ← 星（ゴール）
   ／＼
  👦🎈 ← Player A が到達！

  🎈
  👦  ← Player B はまだ途中

→ その瞬間に終了、Player A の勝利
→ Confetti（紙吹雪）が舞う
→ 子供が喜ぶ
```

- 先に到達した瞬間にゲーム終了
- カジュアルで分かりやすい
- 達成感が強い

### パターン 2: 時間切れ

```
30秒経過

  🎈     🎈
  👦  ← Player A (高度: 400m)

  👦  ← Player B (高度: 350m)

→ 引き分け
→ "Time Up!" 表示
→ 静かに終了
```

- 30 秒以内に誰も到達しなかった
- 引き分け
- 次戦への期待感

---

## ゲームの流れ（1 ゲーム）

### 1. スタート演出（4 秒）

```
地面で二人の子供が風船を持って立っている
↓ (3, 2, 1, Start!)
同時に風船を放す
```

### 2. ゲームプレイ（最大 30 秒）

```
息を吹いて上昇
障害物を避ける
星を目指す
```

### 3. ゴール到達 or 時間切れ

```
先に星に到達 → 即座に終了、勝利演出
30秒経過 → 引き分け
```

### 4. リザルト（5 秒）

```
勝者の発表
Confetti演出
リトライ or 終了選択
```

**合計時間: 約 40 秒〜1 分**  
→ カジュアルで繰り返しプレイしやすい

## 世界観・テーマ

### テーマ

**「孤独だけど、ひとりじゃない」**

- 一人で風船を掴んで空を飛ぶ孤独
- でも、同じ空を見上げる誰かがいる温かさ
- 競争しながらも、共に空を駆け上がる仲間

### 感情の設計

| 要素         | 狙う感情                   |
| ------------ | -------------------------- |
| **息を吹く** | 必死さ、一生懸命さ         |
| **上昇**     | 達成感、浮遊感             |
| **障害物**   | ハラハラ、回避の爽快感     |
| **競争**     | 緊張感、ライバル意識       |
| **ゴール**   | 大きな達成感、喜び         |
| **相手**     | 共感、「同じ空を飛ぶ仲間」 |

### トーン＆マナー

- **切なさ**: ちょっと孤独で、ノスタルジック
- **温かさ**: 誰かと一緒に空を見上げている
- **純粋さ**: 子供の一生懸命さ
- **カジュアル**: 気軽に楽しめる

## プレイヤー体験のデザイン

### 1 分目（初プレイ）

「風船を持った子供？息を吹く？なにこれ」  
→ 興味を持つ

### 2 分目（ゲーム中）

「あ、息吹くと上がる！」  
「電線に引っかかった！」  
「相手が先に行ってる！」  
→ ルールを理解、夢中になる

### 3 分目（ゴール）

「やった！星に届いた！」  
「Confetti きれい！」  
→ 達成感

### 4 分目（リトライ）

「もう一回やりたい！」  
「今度こそ勝つ！」  
→ リプレイ性

## まとめ

**OnlyLonely** は、息を吹いて風船を膨らませ、  
風船を持った子供を星まで導く対戦ゲーム。

シンプルなルールとカジュアルな 30 秒対戦で、  
誰でも気軽に楽しめる。

でも、その裏には「孤独だけど、ひとりじゃない」という  
ちょっと切なくて温かいストーリーがある。

息を吹きかけるたびに、画面も心も、少しだけ明るくなる。
