# 構成

- 「ふわふわ」というテーマを聞いて、真っ先に思いついたのは、風船を飛ばしたり、シャボン玉がふわふわ飛んでたり、たんぽぽの綿毛をふわふわ飛ばしたり。
- 幼少期にハマったあれは、果たして大人になった今でも楽しいものなのか。
- その謎を解明するため、我々調査隊は銀座の奥地へと向かった――。
- そこで、シャボン玉と、風船を購入し、子供の頃のあの気持ちを取り戻すべく、、、
- 風船の写真を写す
- シャボン玉の写真を写す
- 結論、やっぱり楽しいものだった！
- しかし、そんなこと、大人になった今ではなかなか出来ないですよね。
- では、それを作ってしまおう。そんなプロダクトが、、、
- 「ふわふわたいむ」
- まさにその風船で飛ばす経験を、皆さんの iphone 上で再現しました。
- このプロダクトで工夫したところは、、、
- デザインのあらゆるところを「ふわふわ」にする
  - タピオカを持ってしれっと飲む
- 工夫点を伝える
  - テーマについて
    - 「ふわふわ」
    - 自分たちが表現したふわふわは、可愛いイメージの「ふわふわ」です。
    - ひょんなことから、スパにゃんたちは、「ふわふわ」冒険に出かけます。
    - あなたの腕で、呼吸でスパニャンに「ふわふわ」の楽しい旅と、仲間たちとの遊びを楽しんでもらいます
  - 遊びの面白さを開発前に確認済み
    - 息の長いふ～ふゲームをして、インタラクティブに息を吹く体験の楽しさを確認
    - シャボン玉を吹いて、空中でふわふわ浮かんでるシャボン玉を見て、それと触れ合う楽しさを確認
  - テーマ「ふわふわ」の世界観を大切に
    - ゲームの中で、基本的に原宿のような「ゆるふわ」な可愛さを演出
    - ゲームに出てくる要素を「ふわふわ」にする。
      - 風船
      - わたあめ
      - 雲
      - シャボン玉
    - 可愛らしいデザインで、誰もが遊びたくなる UI に
- ゲームのデモをする
- 最後に審査員も巻き込んで Play してもらう

# 評価観点

- テーマ性
  - どれだけテーマに合っているか。
- ユニーク性
  - アイデアの独創性と、機能的な独創性を言いたい
- クオリティ
  - 触ってみて伝わるクオリティがいい
- プレゼン
  - 印象に残るプレゼンがいいな
