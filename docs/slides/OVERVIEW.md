# 発表スライドの概要

# 構成

- タピオカを持って登場
  - 原宿で遊んでて、タピオカを買ってきた
  - DeNA の後輩を巻き込んで、「ベビタピ」を言ってもらう。
    - じゃ、ベビタピで始めましょう！
  - 「じゃ、ゲームしよっか！」
- 工夫点を伝える
  - テーマについて
    - 「ふわふわ」
    - 自分たちが表現したふわふわは、可愛いイメージの「ふわふわ」です。
    - ひょんなことから、スパにゃんたちは、「ふわふわ」冒険に出かけます。
    - あなたの腕で、呼吸でスパニャンに「ふわふわ」の楽しい旅と、仲間たちとの遊びを楽しんでもらいます
  - 遊びの面白さを開発前に確認済み
    - 息の長いふ～ふゲームをして、インタラクティブに息を吹く体験の楽しさを確認
    - シャボン玉を吹いて、空中でふわふわ浮かんでるシャボン玉を見て、それと触れ合う楽しさを確認
  - テーマ「ふわふわ」の世界観を大切に
    - ゲームの中で、基本的に原宿のような「ゆるふわ」な可愛さを演出
    - ゲームに出てくる要素を「ふわふわ」にする。
      - 風船
      - わたあめ
      - 雲
      - シャボン玉
    - 可愛らしいデザインで、誰もが遊びたくなる UI に
- ゲームのデモをする
- 最後に審査員も巻き込んで Play してもらう

# 評価観点

- テーマ性
  - どれだけテーマに合っているか。
- ユニーク性
  - アイデアの独創性と、機能的な独創性を言いたい
- クオリティ
  - 触ってみて伝わるクオリティがいい
- プレゼン
  - 印象に残るプレゼンがいいな
