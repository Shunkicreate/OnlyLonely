# 🎮 ゲーム設計書

## 🌈 世界観・コンセプト

> 「息で飛ばす、ふたりの風船」

空には、誰もいない。  
でも、誰かと同じ空を見上げている。

**OnlyLonely** は、そんな "ふたりの孤独" をつなぐ風のゲーム。  
息を吹きかけるたびに、画面も心も、少しだけ明るくなる。

---

## ゲームコンセプト

ふたりがリアルタイムで「息」を吹きかけて風船を飛ばす対戦ゲーム。

- 息を吹きかけて、自分の風船をより高く飛ばせ
- シンプルだけど、ちょっと切ない
- ふわふわした空の中で、たったひとつの風を信じて戦う

---

## 🎮 ゲームルール

### 基本ルール

1. プレイヤーは iPhone に息を吹きかけます
2. 吹いた強さに応じて、自分の風船が上昇します
3. 上昇と重力がバランスを取り合いながら、ふわふわと舞い上がります
4. 制限時間内に **より高く飛んだ方が勝利**
5. 結果は iPad の中央画面に表示されます

### 補足ルール

- 吹きすぎると風船が揺れて、上昇効率が下がる（ランダム風の影響）
- 息を止めると、ゆっくり下降します
- 上昇中は背景が淡く変化して、到達高度を視覚的に演出

### 雲の仕様

空中には**雲**が配置されており、風船の上昇を妨げる障害物として機能します。

#### 雲の種類（松竹梅）

| 種類 | 難易度 | 挙動                                                                  |
| ---- | ------ | --------------------------------------------------------------------- |
| 松   | 最高   | **通り抜け不可**。完全な障害物として機能し、風船が跳ね返される        |
| 竹   | 中級   | **強い勢いで通り抜け可能**。一定以上の上昇速度が必要                  |
| 梅   | 基本   | **通り抜けにくい + 雷ギミック**。雷に当たると風船が割れ、再生成される |

#### 雷ギミック（梅の雲）

- 梅の雲から定期的に雷が降る
- 雷に当たると：
  1. 風船が割れる演出
  2. 少し落下する（高度ペナルティ）
  3. 新しい風船が生成され、ゲーム続行

#### 雲の配置

- 雲の位置は JSON ファイルで定義
- ゲーム開始時に読み込み、固定配置
- 各プレイヤーの画面で同じ位置に配置
