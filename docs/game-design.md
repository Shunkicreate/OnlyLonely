# 🎮 ゲーム設計書

## 🌈 世界観・コンセプト

> 「息で飛ばす、ふたりの風船」

空には、誰もいない。  
でも、誰かと同じ空を見上げている。

**OnlyLonely** は、そんな "ふたりの孤独" をつなぐ風のゲーム。  
風船を持った子供を操作して、星を目指す対戦レースゲーム。  
息を吹きかけるたびに、画面も心も、少しだけ明るくなる。

詳細なストーリーは [ストーリー・ゲームコンセプト](./story-and-game-concept.md) を参照。

---

## ゲームコンセプト

ふたりがリアルタイムで「息」を吹きかけて、風船を持った子供を星まで導く対戦ゲーム。

- 息を吹きかけて、風船を持った子供を上昇させる
- **先に星（ゴール）に到達した方が勝利**
- 30 秒以内に到達できなければ引き分け
- シンプルだけど、ちょっと切ない
- ふわふわした空の中で、たったひとつの風を信じて戦う

## 🎮 ゲームルール

### 基本ルール

1. プレイヤーは iPhone に息を吹きかけます
2. 吹いた強さに応じて、**風船を持った子供**が上昇します
3. 上昇と重力がバランスを取り合いながら、ふわふわと舞い上がります
4. **先に星（ゴール）に到達した方が即座に勝利**
5. 30 秒以内に誰も到達しなければ**引き分け**
6. 結果は iPad の中央画面に表示されます

### プレイヤーキャラクター

- **風船を持った子供**（2D スプライト）
- 風船の浮力で空を飛ぶ
- 息を吹くと風船が膨らみ、上昇力が増す
- 障害物に当たるとダメージを受ける
- **キャラクター同士の衝突判定**あり（互いに跳ね返る）

詳細は [キャラクター仕様書](./character-spec.md) を参照。

### ゴール（星）

- 空の高い位置に**星**が配置される
- 子供が星に接触した瞬間に**ゲーム終了、勝利**
- 星の高度: **800m** （詳細は [ゲームパラメータ](./game-parameters.md#高度設定) を参照）
- 到達すると Confetti（紙吹雪）が舞い、子供が喜ぶ演出

### 補足ルール

- 吹きすぎると風船が揺れて、上昇効率が下がる（ランダム風の影響）
- 息を止めると、ゆっくり下降します
- 上昇中は背景が淡く変化して、到達高度を視覚的に演出
- **キャラクター同士が接近すると衝突**し、互いに跳ね返る（戦略的な妨害が可能）
- フィールド上に出現する攻撃アイテム（虹色の綿菓子、シャボン玉セット）を取得すると一時的に相手へ妨害効果を与えられる

### 攻撃アイテム

#### 虹色の綿菓子

- 原宿で売られているような大きな虹色の綿菓子が雲付近に浮かぶ
- 触れるとプレイヤーが綿菓子を獲得し、**即座に相手プレイヤーの頭上に虹色の雲**が生成される
- 虹色の雲が数秒間にわたり綿菓子を降らせ、相手のキャラクターがほんの少し下降（ペナルティ値は [ゲームパラメータ](./game-parameters.md#ダメージ設定) を参照）
- 自分には影響がなく、素早く確保することで攻撃チャンスになる

#### シャボン玉セット

- ボトルとストロー型の吹き棒がセットになったアイテム
- 取得すると、相手が表示されている側面（左/右）から**巨大な吹き棒がフィールドにせり出し**、カウントダウン後に虹色のシャボン玉を噴出
- 放たれたシャボン玉が相手のキャラクターに当たると、一瞬怯んで上昇が止まり、軽く下降する（詳細は [ゲームパラメータ](./game-parameters.md#ダメージ設定) を参照）
- シャボン玉は一定時間で消えるため、狙って当てるタイミングが重要

### 画面構成

- **iPad の画面は左右 2 分割**
- 左側: Player A のエリア
- 右側: Player B のエリア
- 物理的には同じ空間を共有しており、キャラクター同士の衝突が発生する

詳細は [画面設計書：ゲームプレイ画面](./screens/04-gameplay-screen-ipad.md) を参照。

### 雲の仕様

空中には**雲**が配置されており、風船の上昇を妨げる障害物として機能します。

#### 雲の種類（松竹梅）

| 種類 | 難易度 | 挙動                                                                  |
| ---- | ------ | --------------------------------------------------------------------- |
| 松   | 基本   | **通り抜けにくい + 雷ギミック**。雷に当たると風船が割れ、再生成される |
| 竹   | 中級   | **強い勢いで通り抜け可能**。一定以上の上昇速度が必要                  |
| 梅   | 最高   | **通り抜け不可**。完全な障害物として機能し、風船が跳ね返される        |

#### 雷ギミック（松の雲）

- 松の雲から定期的に雷が降る
- 雷に当たると：
  1. **風船が割れる演出**（MVP: 透明度チカチカ + 少し下降）
  2. 少し落下する（数値は [ゲームパラメータ](./game-parameters.md#ダメージ設定) を参照）
  3. 一定時間後に風船が復活、ゲーム続行

**MVP 実装**:

- 風船が割れたら、子供の透明度を正弦波でチカチカさせる（無敵時間）
- 同時に少し下降
- 一定時間後に風船と透明度が元に戻る
- 子供が落下して新しい風船を掴む演出は、将来的な拡張

**Note**: 雷ダメージや復活時間などの数値パラメータは [ゲームパラメータ](./game-parameters.md) で一元管理しています。

#### 雲の配置

- 雲の位置は JSON ファイルで定義
- ゲーム開始時に読み込み、固定配置
- 各プレイヤーの画面で同じ位置に配置
