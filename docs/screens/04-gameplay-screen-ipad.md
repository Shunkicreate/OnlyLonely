# 04. ゲームプレイ画面（iPad）

## 対象デバイス

iPad のみ（横向き推奨）

## 役割・目的

- ゲームのメイン画面
- 左右に画面を分割して、両プレイヤーの風船をリアルタイム表示
- iPhone から送信される息の強さ（音圧）を受信し、風船を上昇させる
- 残り時間と高度をリアルタイム表示
- 制限時間終了後、自動的にリザルト画面へ遷移

## 表示要素

### 必須要素

- Player A の風船（左側）
- Player B の風船（右側）
- 各プレイヤーの現在高度
- 残り時間（中央上部）
- 背景（高度に応じて変化）
- **雲（松・竹・梅）** - 障害物として配置
- **雷（梅の雲）** - 梅の雲から発生

### オプション要素

- パーティクルエフェクト（息の視覚化）
- 高度目盛り
- プレイヤー名表示

## インタラクション

### リアルタイム更新

- iPhone から音圧データを受信
- 風船の位置を物理演算で更新
- 30Hz (33ms 間隔) で更新

### 自動遷移

- **プレイヤーが星（ゴール）に到達したら、即座にリザルト画面へ遷移**
- 制限時間が 0 になったら、リザルト画面へ自動遷移

## 画面遷移

### 次の画面

- **05. リザルト画面（iPad）** へ自動遷移（時間切れ時）

## 通信

### 受信メッセージ

#### 息の強さ（音圧）

```json
{
  "type": "wind",
  "playerId": "A",
  "force": 0.72
}
```

- `force`: 0.0 〜 1.0 の範囲

### 送信メッセージ

#### 状態同期（リアルタイム）

```json
{
  "type": "state",
  "playerId": "A",
  "altitude": 250.3,
  "time_remaining": 45
}
```

#### ゲーム終了

```json
{
  "type": "game_end",
  "winner": "A",
  "playerA_altitude": 350.5,
  "playerB_altitude": 280.3
}
```

## 実装メモ

### 使用技術

- SpriteKit で描画
- PhysicsBody で物理演算
- SKEmitterNode でパーティクルエフェクト

### 物理演算

```swift
// 上昇力の計算（仮）
let liftForce = windForce * liftCoefficient
let gravity = -9.8
let resistance = velocity * resistanceCoefficient

let acceleration = liftForce + gravity - resistance
```

### パラメータ（仮）

- ゲーム時間: **30 秒**
- 重力: -9.8
- 上昇力係数: TBD
- 抵抗係数: TBD
- 更新頻度: 30Hz

### 雲システム

- JSON ファイルから雲の配置を読み込み
- 雲の種類（松・竹・梅）ごとに異なる物理挙動
- 雷システム（松の雲のみ）

### 状態管理

- 各プレイヤーの風船位置
- 雲の位置・状態
- 雷の発生状態
- 残り時間
- ゲーム状態（進行中/終了）

## デザインメモ

### カラー

- Player A の風船: 赤系
- Player B の風船: 青系
- 背景: 高度に応じてグラデーション変化
  - 低高度: 淡い青
  - 中高度: 明るい青
  - 高高度: 白に近い青

### アニメーション

- 風船がふわふわと揺れる
- 息を吹くとパーティクルが発生
- 背景が滑らかに変化

### エフェクト

- SKEmitterNode で気流の粒子を表現
- 風船が光る

### サウンド

- 風の音（音圧に応じてピッチ変化）
- 高度に応じた環境音の変化
- 雲衝突音（種類に応じて変化）
- 雷鳴（松の雲）
- 風船が割れる音
- 風船再生成音
