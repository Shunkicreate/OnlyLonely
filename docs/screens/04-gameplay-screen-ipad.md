# 04. ゲームプレイ画面（iPad）

## 対象デバイス

iPad のみ（横向き推奨）

## 役割・目的

- ゲームのメイン画面
- **左右に画面を 2 分割**して、両プレイヤーのキャラクター（風船を持った子供）をリアルタイム表示
- 物理的には同じ空間を共有しており、**キャラクター同士の衝突判定**が発生する
- iPhone から送信される息の強さ（音圧）を受信し、キャラクターを上昇させる
- 残り時間と高度、星（ゴール）をリアルタイム表示
- 先に星に到達、または制限時間終了後、自動的にリザルト画面へ遷移

## 表示要素

### 必須要素

- **Player A のキャラクター**（左側）- 風船を持った子供
- **Player B のキャラクター**（右側）- 風船を持った子供
- **星（ゴール）** - 両エリアの高い位置に表示
- 各プレイヤーの現在高度
- 残り時間（中央上部）
- 背景（高度に応じて変化）
- **雲（松・竹・梅）** - 障害物として配置
- **雷（松の雲）** - 松の雲から発生
- **画面分割ライン** - 中央の縦線（薄い線 or 透明）

### オプション要素

- パーティクルエフェクト（息の視覚化）
- 高度目盛り
- プレイヤー名表示

### レイアウトの説明

- **左半分**: Player A のエリア
- **右半分**: Player B のエリア
- **中央の縦線**: 画面分割ライン（薄いグレー or 透明）
- **同じ空間**: 物理的には同じ高度空間を共有
- **キャラクター**: 風船を持った子供（👦🎈）
- **星（⭐）**: 両エリアの最高高度（800m）に表示
- **雲**: 松（⚡ 付き）、竹（通過可能）、梅（通過不可）
- **障害物**: 電線、カラスなども配置される

## インタラクション

### リアルタイム更新

- iPhone から音圧データを受信
- キャラクター（風船を持った子供）の位置を物理演算で更新
- 30Hz (33ms 間隔) で更新
- **キャラクター同士の衝突判定**を毎フレーム実行

### キャラクター同士の衝突

- 両プレイヤーが同じ高度で近い位置にいる時、**衝突判定**が発生
- 衝突時は互いに跳ね返る（反発力）
- 風船は割れない（ダメージなし）
- 「ポンッ」という衝突音が鳴る
- 戦略的な妨害プレイが可能

詳細は [キャラクター仕様書：衝突判定](../character-spec.md#キャラクター同士の衝突判定) を参照。

### 自動遷移

- **プレイヤーが星（ゴール）に到達したら、即座にリザルト画面へ遷移**
- 制限時間が 0 になったら、リザルト画面へ自動遷移

## 通信

### 受信メッセージ

#### 息の強さ（音圧）

```json
{
  "type": "wind",
  "playerId": "A",
  "force": 0.72
}
```

- `force`: 0.0 〜 1.0 の範囲

### 送信メッセージ

#### 状態同期（リアルタイム）

```json
{
  "type": "state",
  "playerId": "A",
  "altitude": 250.3,
  "time_remaining": 45
}
```

#### ゲーム終了

```json
{
  "type": "game_end",
  "winner": "A",
  "playerA_altitude": 350.5,
  "playerB_altitude": 280.3
}
```

## 実装メモ

### 使用技術

- SpriteKit で描画
- PhysicsBody で物理演算
- SKEmitterNode でパーティクルエフェクト

### 画面分割の実装

- **左右 2 分割**: iPad の画面を縦半分に分割
- 各エリアは独立した `SKScene` または `SKCameraNode` で管理
- 物理空間は共有（同じ `physicsWorld`）
- 中央の分割線は薄いグレー（alpha: 0.2）または透明

### キャラクター衝突システム

- `PhysicsCategory` を使って衝突カテゴリを定義
- Player A と Player B はそれぞれ独立した物理ボディを持つ
- `collisionBitMask` で相手プレイヤーと雲との衝突を有効化
- `contactTestBitMask` で衝突検出イベントを設定

### 物理演算

- 上昇力: 息の強さ（音圧）× 上昇力係数
- 重力: 常に下向きに作用
- 抵抗: 速度に応じた空気抵抗
- 加速度 = 上昇力 + 重力 - 抵抗

### パラメータ（仮）

- ゲーム時間: **30 秒**
- 重力: -9.8
- 上昇力係数: TBD
- 抵抗係数: TBD
- 更新頻度: 30Hz

### 雲システム

- JSON ファイルから雲の配置を読み込み
- 雲の種類（松・竹・梅）ごとに異なる物理挙動
- 雷システム（松の雲のみ）

### 状態管理

- 各プレイヤーのキャラクター位置
- 雲の位置・状態
- 雷の発生状態
- 星（ゴール）の位置
- 残り時間
- ゲーム状態（進行中/終了）
- キャラクター衝突状態

## デザインメモ

### カラー

- Player A のキャラクター: 赤系
- Player B のキャラクター: 青系
- 画面分割ライン: 薄いグレー（alpha: 0.2）または透明
- 背景: 高度に応じてグラデーション変化
  - 低高度: 淡い青
  - 中高度: 明るい青
  - 高高度: 白に近い青

### アニメーション

- キャラクター（風船を持った子供）がふわふわと揺れる
- 息を吹くとパーティクルが発生
- 背景が滑らかに変化
- キャラクター衝突時に軽く跳ね返るアニメーション

### エフェクト

- SKEmitterNode で気流の粒子を表現
- 風船が光る

### サウンド

- 風の音（音圧に応じてピッチ変化）
- 高度に応じた環境音の変化
- 雲衝突音（種類に応じて変化）
- 雷鳴（松の雲）
- 風船が割れる音
- 風船再生成音
- キャラクター同士の衝突音（ポンッという軽い音）
- 障害物衝突時の固有効果音（[サウンド設計書：障害物衝突音](../sound-design.md#9-障害物衝突時のフィードバック音) を参照）

### 衝突時のフィードバック

#### ビジュアルフィードバック

- **キャラクター衝突**: 衝突地点に白い波紋エフェクト、両キャラクターが軽く点滅
- **障害物衝突**: 障害物ごとに固有のエフェクト（[ビジュアル設計書：衝突エフェクト](../visual-design.md#衝突時のフィードバックエフェクト) を参照）
- **画面振動**: 大きな衝突（梅の雲、隕石）では画面全体が軽く振動（0.1〜0.2秒）
- **スローモーション**: 重要な衝突（隕石、雷）では瞬間的にスローモーション演出（0.3倍速、0.2秒間）

#### オーディオフィードバック

- **空間オーディオ**: 衝突位置（左右）に応じてステレオパンニング
- **音量変化**: 衝突の強度に応じて音量が変化（50%〜100%）
- **固有効果音**: 各障害物ごとに異なる衝突音を再生

#### 実装のポイント

- 衝突検出時に `SKPhysicsContactDelegate` の `didBegin(_:)` メソッドで処理
- 衝突タイプに応じてビジュアルエフェクト、サウンド、画面振動を実行
- 画面振動は `SKAction` のシーケンスで実装
- 空間オーディオは `AVAudioEngine` を使用して左右の位置に応じたパンニング

## 入力バリデーション

### 風力入力（force 値）

| 項目           | ルール                              | エラー時の挙動                       |
| -------------- | ----------------------------------- | ------------------------------------ |
| 値の範囲       | 0.0 〜 1.0                          | 範囲外の値はクランプ（0.0 or 1.0）  |
| データ型       | Float または Double                 | 型エラー時は 0.0 を設定              |
| 受信頻度       | 最大 30Hz (33ms 間隔)               | 高頻度メッセージは間引き処理         |
| playerId       | 接続済みプレイヤーの ID と一致      | 不一致時は無視                       |
| Null/未定義    | 不可                                | Null の場合は 0.0 を設定             |
