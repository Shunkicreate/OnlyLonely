# 09. カウントダウン画面（iPhone）

## 対象デバイス

iPhone のみ

## 役割・目的

- ゲーム開始前のカウントダウンを表示
- 3, 2, 1, Start! の演出
- カウントダウン終了後、ゲームプレイ画面へ自動遷移

## 表示要素

### 必須要素

- カウントダウン数字（3, 2, 1）
- Start! の表示

### オプション要素

- 背景アニメーション
- カウントダウン音

## インタラクション

### 自動進行

- 3, 2, 1 を 1 秒ごとに表示
- Start! を 0.5 秒表示
- 自動的にゲームプレイ画面へ遷移

## 画面遷移

### 次の画面

- **11. ゲームプレイ画面（iPhone）** へ自動遷移

## 通信

### 受信メッセージ

#### カウントダウン開始

```json
{
  "type": "countdown_start"
}
```

### 送信メッセージ

なし

## 実装メモ

### 使用技術

- SwiftUI で画面実装
- Timer でカウントダウン

### タイミング

- 3: 1 秒表示
- 2: 1 秒表示
- 1: 1 秒表示
- Start!: 0.5 秒表示
- 合計: 3.5 秒

### 同期

- iPad と iPhone のカウントダウンを同期
- iPad からカウントダウン開始メッセージを受信してスタート

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- 数字: 大きく、白または明るい色
- Start!: 明るい色、太字

### アニメーション

- 数字がフェードイン・スケールアップ
- 数字が消える時はフェードアウト
- Start! は弾けるようなアニメーション

### サウンド

- カウントダウン音（3, 2, 1）
- Start! の音（高めのピッチ）
