# 01. タイトル画面

## 対象デバイス

iPad / iPhone 共通

## 役割・目的

- アプリ起動時に表示される最初の画面
- ゲームのタイトルと世界観を伝える
- デバイスを自動判定して、適切な画面へ遷移

## 表示要素

### 必須要素

- ゲームタイトル: **OnlyLonely**
- キャッチコピー: 「息で飛ばす、ふたりの風船」
- スタートボタン

### オプション要素

- 風船のアニメーション（ふわふわと浮遊）
- 背景: 空のグラデーション
- BGM / 環境音

## UI レイアウト

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│                                     │
│           OnlyLonely                │
│                                     │
│      「息で飛ばす、ふたりの風船」    │
│                                     │
│              🎈  🎈                 │
│                                     │
│                                     │
│         [ タップしてスタート ]       │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

## インタラクション

### タップしてスタート

- 画面全体をタップ可能
- タップするとデバイスを自動判定して次の画面に遷移

## 画面遷移

### 次の画面

デバイスを自動判定して、適切な画面へ遷移：

- iPad の場合: **03. 接続待機画面（iPad）** へ遷移
- iPhone の場合: **06. プレイヤー名入力画面（iPhone）** へ遷移

## 通信

なし

## 実装メモ

### 使用技術

- SwiftUI でシンプルに実装
- アニメーションは SwiftUI Animation または SpriteKit

### デバイス判定

```swift
#if os(iOS)
  if UIDevice.current.userInterfaceIdiom == .pad {
      // iPad として動作
  } else {
      // iPhone として動作
  }
#endif
```

### 状態管理

- デバイスタイプ（iPad / iPhone）を自動判定して保持

## デザインメモ

### カラー

- 背景: 淡い空色のグラデーション
- タイトル: 白または淡い色
- フォント: 柔らかい雰囲気のフォント

### アニメーション

- 風船がゆっくりふわふわと上下に動く
- タイトルがフェードイン
- 「タップしてスタート」が点滅またはパルス

### サウンド

- 静かな環境音（風の音）
- タップ時に小さな効果音
