# 06. 接続画面（iPhone）

## 対象デバイス

iPhone のみ

## 役割・目的

- iPad の WebSocket サーバーに接続
- IP アドレスまたは QR コードで接続情報を入力
- 接続成功後、プレイヤー選択画面へ遷移

## 表示要素

### 必須要素

- 画面タイトル: 「iPad に接続」
- IP アドレス入力フィールド
- 接続ボタン
- 接続状態（接続中...、接続失敗など）

### オプション要素

- QR コードスキャンボタン
- 最近接続した履歴
- 戻るボタン

## インタラクション

### IP アドレス入力

- キーボードで IP アドレスを入力
- デフォルト値: 192.168.1.100（仮）

### ポート番号入力

- デフォルト値: 8080（仮）

### QR コードで接続ボタン

- タップでカメラを起動
- iPad の QR コードをスキャン
- 接続情報を自動入力

### 接続するボタン

- タップで WebSocket 接続を試行
- 接続中はローディング表示
- 接続成功: プレイヤー選択画面へ遷移
- 接続失敗: エラーメッセージ表示

### 戻るボタン

- タップでデバイス選択画面に戻る

## 画面遷移

### 次の画面（接続成功時）

- **07. プレイヤー選択画面（iPhone）** へ遷移

### 戻る

- **02. デバイス選択画面** へ戻る

## 通信

### WebSocket 接続

- `ws://[IP]:[PORT]` に接続

### 送信メッセージ

#### 接続リクエスト

```json
{
  "type": "connect",
  "device": "iPhone"
}
```

### 受信メッセージ

#### 接続確認

```json
{
  "type": "connection_accepted"
}
```

#### 接続拒否

```json
{
  "type": "connection_rejected",
  "reason": "Server is full"
}
```

## 実装メモ

### 使用技術

- SwiftUI で画面実装
- URLSessionWebSocketTask でクライアント接続
- AVFoundation で QR コードスキャン（オプション）

### 状態管理

```swift
enum ConnectionState {
    case idle
    case connecting
    case connected
    case failed(Error)
}
```

### エラーハンドリング

- 接続タイムアウト（10 秒）
- 接続失敗時のリトライ
- ネットワークエラーの表示

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- 入力フィールド: 白背景
- ボタン: 淡い色

### インタラクション

- 接続中はローディングアニメーション
- 接続成功時にチェックマークアニメーション
- 接続失敗時にエラーメッセージを赤で表示
