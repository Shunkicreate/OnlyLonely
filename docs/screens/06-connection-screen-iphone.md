# 06. 接続画面（iPhone）

## 対象デバイス

iPhone のみ

## 役割・目的

- iPad の MultipeerConnectivity ホストに接続（招待承諾）
  - 近傍のホスト一覧から接続先を選択（自動検出）
- 接続成功後、プレイヤー選択画面へ遷移

## 表示要素

### 必須要素

- 画面タイトル: 「iPad に接続」
  - ホスト選択用リスト（自動検出）
- 接続ボタン
- 接続状態（接続中...、接続失敗など）

### オプション要素

- 最近接続した履歴
- 戻るボタン

## インタラクション

### サーバー選択

- 検出されたサーバーのリストからタップで接続先を選択
- サーバーが自動検出できない場合や手動で入力したい場合には下部の入力欄を利用
- 最近接続したサーバーの履歴から選ぶことも可能

### IP アドレス/ポート入力

- キーボードで IP アドレス・ポート番号を手動入力
- デフォルト値: 192.168.1.100（仮） / 8080（仮）

### 接続するボタン

- 検出したホストへ P2P 接続（招待承諾）を試行
- 接続中はローディング表示
- 接続成功: プレイヤー選択画面へ遷移
- 接続失敗: エラーメッセージ表示

### 戻るボタン

- タップでデバイス選択画面に戻る

## 画面遷移

### 次の画面（接続成功時）

- **07. プレイヤー選択画面（iPhone）** へ遷移

### 戻る

- **02. デバイス選択画面** へ戻る

## 通信

### P2P 接続（MultipeerConnectivity）

- `MCNearbyServiceAdvertiser` を開始し、ホストからの招待を承諾

### 送信メッセージ

#### 接続リクエスト

```json
{
  "type": "connect",
  "device": "iPhone"
}
```

### 受信メッセージ

#### 接続確認

```json
{
  "type": "connection_accepted"
}
```

#### 接続拒否

```json
{
  "type": "connection_rejected",
  "reason": "Server is full"
}
```

## 実装メモ

### 使用技術

- SwiftUI で画面実装
- `MCNearbyServiceAdvertiser` を起動し、ホストからの招待を待機
- Bonjour などでサーバー自動検出（オプション）

### 状態管理

```swift
enum ConnectionState {
    case idle
    case connecting
    case connected
    case failed(Error)
}
```

### エラーハンドリング

- 接続タイムアウト（10 秒）
- 接続失敗時のリトライ
- ネットワークエラーの表示

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- 入力フィールド: 白背景
- ボタン: 淡い色

### インタラクション

- 接続中はローディングアニメーション
- 接続成功時にチェックマークアニメーション
- 接続失敗時にエラーメッセージを赤で表示

## 入力バリデーション

### IP アドレス入力

| 項目           | ルール                              | エラー時の挙動                       |
| -------------- | ----------------------------------- | ------------------------------------ |
| 形式           | IPv4 形式（xxx.xxx.xxx.xxx）        | 不正形式の場合は接続ボタン無効化     |
| 各オクテット   | 0-255 の範囲                        | 範囲外の値は赤文字でエラー表示       |
| 空欄           | デフォルト値を使用                  | 空欄時は `192.168.1.100` を使用      |
| 入力可能文字   | 数字とドット（`.`）のみ             | それ以外の文字は入力不可             |

### ポート番号入力

| 項目           | ルール                              | エラー時の挙動                       |
| -------------- | ----------------------------------- | ------------------------------------ |
| 形式           | 数値のみ                            | 数値以外は入力不可                   |
| 範囲           | 1024-65535                          | 範囲外の値は赤文字でエラー表示       |
| 空欄           | デフォルト値を使用                  | 空欄時は `8080` を使用               |
| 最大桁数       | 5 桁                                | 6 桁目以降は入力不可                 |
