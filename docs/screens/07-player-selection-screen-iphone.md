# 07. プレイヤー名入力画面（iPhone）

## 対象デバイス

iPhone のみ

## 役割・目的

- プレイヤー名を入力して参加
- 入力後、キャリブレーション画面へ遷移（またはスキップして待機画面へ）

## 表示要素

### 必須要素

- 画面タイトル: 「プレイヤー名を入力」
- プレイヤー名入力フィールド
- 参加ボタン

### オプション要素

- デフォルト名の提案（例: プレイヤー 1、プレイヤー 2）
- 戻るボタン

## インタラクション

### プレイヤー名入力

- キーボードで名前を入力
- 最大文字数: 10 文字（仮）
- 空欄の場合: デフォルト名を自動設定（例: プレイヤー 1）

### 参加するボタン

- タップで名前を確定し、次の画面へ遷移
- 名前が空欄の場合は、デフォルト名を使用

### 戻るボタン

- タップで接続画面に戻る
- P2P セッションは維持

## 画面遷移

### 次の画面（名前入力後）

- **09. 待機画面（iPhone）** へ遷移

### 戻る

- **06. 接続画面（iPhone）** へ戻る（接続は切断）

## 通信

### 送信メッセージ

#### プレイヤー参加

```json
{
  "type": "player_join",
  "playerName": "たろう",
  "playerId": "uuid-xxxx-xxxx"
}
```

### 受信メッセージ

#### 参加確認

```json
{
  "type": "player_join_accepted",
  "playerId": "uuid-xxxx-xxxx",
  "assignedSlot": 0
}
```

#### 参加拒否（満員）

```json
{
  "type": "player_join_rejected",
  "reason": "Server is full"
}
```

## 実装メモ

### 使用技術

- SwiftUI で画面実装

### 状態管理

- 入力されたプレイヤー名を保持
- 自分の Player ID（UUID）を生成・保持
- 割り当てられたスロット番号を保持

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- 入力フィールド: 白背景
- ボタン: 淡い色

### インタラクション

- 入力中はキーボードを表示
- 参加ボタンをタップ時にスケールアニメーション

### アニメーション

- 名前入力完了後、フェードアウトして次の画面へ
- 風船がふわふわと動く

## 入力バリデーション

### プレイヤー名入力

| 項目           | ルール                                                | エラー時の挙動                       |
| -------------- | ----------------------------------------------------- | ------------------------------------ |
| 最大文字数     | 10 文字以内（[game-parameters.md](../game-parameters.md) 参照） | 11 文字目以降は入力不可              |
| 最小文字数     | 0 文字（空欄可）                                      | 空欄時は自動的にデフォルト名を設定   |
| 使用可能文字   | 全角・半角英数字、ひらがな、カタカナ、漢字、絵文字    | すべて使用可能（制限なし）           |
| 空白のみ       | 不可                                                  | 空白のみの場合はデフォルト名を設定   |
| デフォルト名   | 「プレイヤー1」「プレイヤー2」など                    | 空欄で送信時に自動設定               |
| トリミング     | 先頭・末尾の空白を自動削除                            | 送信前に自動処理                     |
