# 02. スタート演出画面（iPad）

## 対象デバイス

iPad のみ

## 役割・目的

- ゲーム開始前の演出画面
- 二人のプレイヤーが風船を持って立っている
- カウントダウン後、同時に風船を放してゲームスタート
- プレイヤーの期待感を高める

## 表示要素

### 必須要素

- Player A のキャラクター（左側）
- Player B のキャラクター（右側）
- 各プレイヤーが持つ風船
- カウントダウン表示（3, 2, 1, Start!）

### オプション要素

- 背景（地面、空）
- 風のエフェクト
- プレイヤー名表示

## インタラクション

### 自動進行

1. カウントダウン開始（3, 2, 1）
2. "Start!" 表示と同時に風船が上昇開始
3. ゲームプレイ画面へ自動遷移

### タイミング

- 3, 2, 1: 各 1 秒
- Start!: 0.5 秒表示
- 風船放出アニメーション: 0.5 秒
- 合計: 約 4 秒

## 実装メモ

### 使用技術

- SpriteKit でアニメーション実装
- キャラクターは SKSpriteNode
- 風船の上昇アニメーション

### アニメーション

1. **待機アニメーション**

   - キャラクターが軽く呼吸しているような動き
   - 風船がふわふわと揺れる

2. **カウントダウンアニメーション**

   - 数字が大きく表示される
   - 数字が消える時にフェードアウト

3. **風船放出アニメーション**
   - キャラクターの手から風船が離れる
   - 風船が勢いよく上昇
   - パーティクルエフェクトが発生

## デザインメモ

### カラー

- 背景: 地面は緑、空は青のグラデーション
- Player A のキャラクター: TBD
- Player B のキャラクター: TBD
- 風船: Player A は赤系、Player B は青系

### アニメーション

- キャラクターのアニメーション: シンプルな 2D スプライト
- 風船の放出: ふわっと上昇
- カウントダウン: スケールアップ → フェードアウト

### エフェクト

- 風のパーティクル（地面から上へ）
- 風船放出時のキラキラエフェクト

### サウンド

- カウントダウン音: ピッ、ピッ、ピッ
- Start! の音: ピーッ（高めのピッチ）
- 風船放出音: ポンッという軽い音
- 風のサウンド: ヒューという環境音
