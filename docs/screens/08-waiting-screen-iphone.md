# 08. 待機画面（iPhone）

## 対象デバイス

iPhone のみ

## 役割・目的

- 他のプレイヤーの準備完了を待つ
- 自分と相手の準備状態を表示
- 両プレイヤーが準備完了になったら、カウントダウン画面へ自動遷移

## 表示要素

### 必須要素

- 画面タイトル: 「準備完了！」
- 自分の状態: 準備完了
- 相手の状態: 準備中 / 準備完了
- 待機メッセージ

### オプション要素

- 風船のアニメーション
- BGM / 環境音
- キャンセルボタン

## UI レイアウト

```
┌─────────────────────────┐
│                         │

│                         │
│                         │
│  [ キャンセル ]         │
│                         │

```

## インタラクション

### 自動更新

- 相手の状態がリアルタイムで更新される
- 両プレイヤーが準備完了になったら、自動的にカウントダウン画面へ遷移

### キャンセルボタン

- タップでキャリブレーション画面に戻る
- または接続を切断してタイトルに戻る

## 画面遷移

### 次の画面（両プレイヤー準備完了時）

- **10. カウントダウン画面（iPhone）** へ自動遷移

### 戻る

- **08. キャリブレーション画面（iPhone）** または **01. タイトル画面** へ戻る

## 通信

### 受信メッセージ

#### 相手の準備完了

```json
{
  "type": "player_ready",
  "playerId": "B"
}
```

#### ゲーム開始

```json
{
  "type": "game_start"
}
```

### 送信メッセージ

なし（既にキャリブレーション完了メッセージを送信済み）

## 実装メモ

### 使用技術

- SwiftUI で画面実装

### 状態管理

- 自分の準備状態: 準備完了
- 相手の準備状態: 準備中 / 準備完了

### 自動遷移

- 両プレイヤーが準備完了になったら、0.5 秒後にカウントダウン画面へ遷移

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- 準備完了: 緑色のチェックマーク
- 準備中: 黄色のローディングアイコン

### アニメーション

- 風船がふわふわと上下に動く
- 準備中はローディングアニメーション
- 相手が準備完了になったら、チェックマークアニメーション

### サウンド

- 静かな環境音（風の音）
- 相手が準備完了になったら、通知音
