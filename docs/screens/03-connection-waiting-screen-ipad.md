# 03. 接続待機画面（iPad）

## 対象デバイス

iPad のみ

## 役割・目的

- MultipeerKit のホストとして待受し、iPhone からの接続を待つ
- 接続状況をリアルタイムで表示
- 両プレイヤーが接続＆キャリブレーション完了後、自動的にゲーム画面へ遷移

## 表示要素

### 必須要素

- 画面タイトル: 「プレイヤーを待っています」
    - 近傍ホストとしての表示名（serviceType）
- 接続状況
  - Player A: 未接続 / 接続中 / 準備完了
  - Player B: 未接続 / 接続中 / 準備完了
- ステータスメッセージ

### オプション要素

- キャンセルボタン（タイトルに戻る）

## インタラクション

### 自動更新

- iPhone が接続すると、ステータスがリアルタイムで更新される
- Player A / B の状態変化を表示

### キャンセルボタン

- タップでサーバーを停止し、タイトル画面に戻る

### 自動遷移

- 両プレイヤーが「準備完了」になると、自動的にゲームプレイ画面へ遷移

## 画面遷移

### 次の画面

- **04. ゲームプレイ画面（iPad）** へ自動遷移（両プレイヤー準備完了時）

### 戻る

- **01. タイトル画面** へ戻る（キャンセル時）

## 通信

### P2P ホスト起動（MultipeerKit）

- `MultipeerTransceiver` をホストモードで起動し、周辺端末を発見・招待
- `serviceType`: `onlylonelyp2p`

### 受信メッセージ

#### プレイヤー接続

```json
{
  "type": "connect",
  "playerId": "A"
}
```

#### プレイヤー選択

```json
{
  "type": "player_selected",
  "playerId": "A"
}
```

#### キャリブレーション完了

```json
{
  "type": "calibration_complete",
  "playerId": "A"
}
```

### 送信メッセージ

#### 接続確認

```json
{
  "type": "connection_accepted",
  "playerId": "A"
}
```

#### ゲーム開始

```json
{
  "type": "game_start"
}
```

## 実装メモ

### 使用技術

- SwiftUI で画面実装
- MultipeerKit で P2P 接続（内部で MultipeerConnectivity を利用）

### 状態管理

- プレイヤーの接続状態を管理
  ```swift
  enum PlayerState {
      case disconnected
      case connected
      case calibrating
      case ready
  }
  ```

### ネットワーク

- 近接 P2P（Bluetooth/Wi‑Fi）を前提
- Bonjour は MultipeerKit に内包

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- ステータス表示: 状態に応じた色
  - 未接続: グレー
  - 接続中: イエロー
  - 準備完了: グリーン

### アニメーション

- 接続中は点滅またはローディングアニメーション
- 準備完了時にチェックマークアニメーション
