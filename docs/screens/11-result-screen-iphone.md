# 11. リザルト画面（iPhone）

## 対象デバイス

iPhone のみ

## 役割・目的

- ゲーム終了後、勝敗結果を表示
- 自分と相手の最高高度を表示
- リトライまたはタイトルに戻る選択肢を提供

## 表示要素

### 必須要素

- リトライボタン
- タイトルに戻るボタン

### オプション要素

- 勝敗結果（勝ち / 負け / 引き分け）
- 自分の最高高度
- 相手の最高高度
- 勝利メッセージ / 敗北メッセージ
- 統計情報（プレイ時間、平均高度など）

## インタラクション

### もう一度ボタン

- タップで「接続画面（iPhone）」に戻る
- 同じ iPad に再接続

### 終了ボタン

- タップで「タイトル画面」に戻る
- P2P 接続（セッション）を切断

## 画面遷移

### 次の画面（もう一度）

- **06. 接続画面（iPhone）** へ遷移

### 次の画面（終了）

- **01. タイトル画面** へ遷移

## 通信

### 受信メッセージ

#### ゲーム終了

```json
{
  "type": "game_end",
  "winner": "A",
  "playerA_altitude": 350.5,
  "playerB_altitude": 280.3
}
```

### 送信メッセージ

#### リトライ

```json
{
  "type": "retry",
  "playerId": "A"
}
```

#### 切断

```json
{
  "type": "disconnect",
  "playerId": "A"
}
```

## 実装メモ

### 使用技術

- SwiftUI で画面実装

### 状態管理

- 勝敗結果
- 自分と相手の最高高度

### 判定

- 自分の高度 > 相手の高度: 勝利
- 自分の高度 < 相手の高度: 敗北
- 自分の高度 == 相手の高度: 引き分け

## デザインメモ

### カラー

- 勝利: 明るい色、金色のエフェクト
- 敗北: 少し暗めの色
- 引き分け: 中間の色

### アニメーション

- リザルト画面表示時にフェードイン
- 勝利時は風船が空に消える
- 高度の数値がカウントアップ
- 勝利時はキラキラエフェクト

### サウンド

- 勝利音（小さな鐘の音＋残響）
- 敗北音（静かな音）
- タイトル「OnlyLonely」が浮かぶ演出音

### メッセージ

- 勝利: 「素晴らしい！」「おめでとう！」
- 敗北: 「もう一度挑戦しよう」「惜しかった」
- 引き分け: 「引き分け！」
