# 06. プレイヤー名入力画面（iPhone）

## 対象デバイス

iPhone のみ

## 役割・目的

- ゲーム参加前にプレイヤー名を入力
- 名前を入力後、接続画面へ遷移
- 入力した名前は接続時に iPad へ送信され、相手プレイヤーにも表示される

## 表示要素

### 必須要素

- 画面タイトル: 「プレイヤー名を入力」
- プレイヤー名入力フィールド
- 参加ボタン

### オプション要素

- デフォルト名の提案（例: プレイヤー 1、プレイヤー 2）
- 戻るボタン

## インタラクション

### プレイヤー名入力

- キーボードで名前を入力
- 最大文字数: 10 文字（仮）
- 空欄の場合: デフォルト名を自動設定（例: プレイヤー 1）

### 次へボタン

- タップで名前を確定し、接続画面へ遷移
- 名前が空欄の場合は、デフォルト名を使用

### 戻るボタン

- タップでタイトル画面に戻る

## 画面遷移

### 次の画面（名前入力後）

- **07. 接続画面（iPhone）** へ遷移

### 戻る

- **01. タイトル画面** へ戻る

## 通信

この画面では通信は発生しません。  
プレイヤー名は次の接続画面で iPad へ送信されます。

## 実装メモ

### 使用技術

- SwiftUI で画面実装

### 状態管理

- 入力されたプレイヤー名を保持（ローカル変数）
- 名前は次の接続画面へ引き継がれる

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- 入力フィールド: 白背景
- ボタン: 淡い色

### インタラクション

- 入力中はキーボードを表示
- 参加ボタンをタップ時にスケールアニメーション

### アニメーション

- 名前入力完了後、フェードアウトして次の画面へ
- 風船がふわふわと動く

## 入力バリデーション

### プレイヤー名入力

| 項目         | ルール                                                          | エラー時の挙動                     |
| ------------ | --------------------------------------------------------------- | ---------------------------------- |
| 最大文字数   | 10 文字以内（[game-parameters.md](../game-parameters.md) 参照） | 11 文字目以降は入力不可            |
| 最小文字数   | 0 文字（空欄可）                                                | 空欄時は自動的にデフォルト名を設定 |
| 使用可能文字 | 全角・半角英数字、ひらがな、カタカナ、漢字、絵文字              | すべて使用可能（制限なし）         |
| 空白のみ     | 不可                                                            | 空白のみの場合はデフォルト名を設定 |
| デフォルト名 | 「プレイヤー 1」「プレイヤー 2」など                            | 空欄で送信時に自動設定             |
| トリミング   | 先頭・末尾の空白を自動削除                                      | 送信前に自動処理                   |
