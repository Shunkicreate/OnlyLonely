# 08. キャリブレーション画面（iPhone）

**※ この画面は必須要件ではありません（MVP では省略可能）**

## 対象デバイス

iPhone のみ

## 役割・目的

- マイクで息の音圧を取得し、感度を調整
- プレイヤーが息を吹いて、適切な音圧レベルを設定
- キャリブレーション完了後、待機画面へ遷移
- **MVP では、デフォルト値を使用してこの画面をスキップすることも可能**

## 表示要素

### 必須要素

- 画面タイトル: 「息の感度調整」
- 説明テキスト: 「iPhone に息を吹きかけてください」
- 音圧レベルメーター（リアルタイム）
- 目標範囲の表示
- 完了ボタン

### オプション要素

- プレビュー風船（息を吹くと上昇）
- 再調整ボタン
- スキップボタン（デフォルト値を使用）

## インタラクション

### リアルタイム音圧取得

- マイクで音圧をリアルタイムで取得
- 音圧レベルメーターに表示
- プレビュー風船が上下に動く

### 完了ボタン

- タップでキャリブレーション完了
- 現在の設定を保存
- 待機画面へ遷移

### スキップボタン

- タップでキャリブレーションをスキップ
- デフォルトの感度を使用
- 待機画面へ遷移

## 画面遷移

## 実装メモ

### 使用技術

- AVAudioEngine でマイク入力
- RMS (Root Mean Square) で音圧計算
- SwiftUI で画面実装

### 音圧計算

```swift
// RMS 計算（仮）
let rms = sqrt(samples.map { $0 * $0 }.reduce(0, +) / Float(samples.count))
let db = 20 * log10(rms)
let normalizedForce = (db - minDB) / (maxDB - minDB)
```

### パラメータ

- サンプリングレート: 44100 Hz（仮）
- バッファサイズ: 1024（仮）
- 最小音圧: -60 dB（仮）
- 最大音圧: 0 dB（仮）

### 状態管理

- 現在の音圧レベル
- 最小・最大閾値
- キャリブレーション完了フラグ

### マイク権限

- マイク使用許可をリクエスト
- 拒否された場合の処理

## デザインメモ

### カラー

- 背景: 空色のグラデーション
- 音圧メーター: グラデーション（低: 緑 → 高: 赤）
- 目標範囲: 黄色でハイライト

### アニメーション

- 音圧に応じてメーターがリアルタイムで動く
- プレビュー風船がふわふわと上下
- 息を吹くとパーティクルが発生

### サウンド

- 音圧に応じてフィードバック音（オプション）
