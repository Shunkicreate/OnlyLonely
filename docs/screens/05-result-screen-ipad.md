# 05. リザルト画面（iPad）

## 対象デバイス

iPad のみ

## 役割・目的

- ゲーム終了後、勝敗結果を表示
- 各プレイヤーの最高高度を表示
- リトライまたはタイトルに戻る選択肢を提供

## 表示要素

### 必須要素

- 勝者の表示（Player A or Player B）
- 各プレイヤーの最高高度
- リトライボタン
- タイトルに戻るボタン

### オプション要素

- 勝者の風船が空に消える演出
- 花火やキラキラエフェクト
- 勝利メッセージ

## インタラクション

### もう一度ボタン

- タップで「接続待機画面（iPad）」に戻る
- 同じプレイヤーで再度プレイ

### 終了ボタン

- タップで「タイトル画面」に戻る
- P2P ホスト（Advertiser/Browser）を停止

## 画面遷移

### 次の画面（もう一度）

- **03. 接続待機画面（iPad）** へ遷移

### 次の画面（終了）

- **01. タイトル画面** へ遷移

## 通信

### 送信メッセージ

#### リトライ

```json
{
  "type": "retry"
}
```

#### ゲーム終了

```json
{
  "type": "game_over"
}
```

## 実装メモ

### 使用技術

- SwiftUI または SpriteKit で実装
- 勝者の風船演出は SpriteKit で実装

### 状態管理

- 勝者
- 各プレイヤーの最高高度

### 演出

- 勝者の風船が空に消えるアニメーション
- 花火やキラキラエフェクト（SKEmitterNode）

## デザインメモ

### カラー

- 勝者の色を強調（Player A なら赤系、Player B なら青系）
- 背景: 明るい空色

### アニメーション

- リザルト画面表示時にフェードイン
- 勝者の風船が空に消える
- 高度の数値がカウントアップ

### サウンド

- 勝利音（小さな鐘の音＋残響）
- タイトル「OnlyLonely」が浮かぶ演出音
