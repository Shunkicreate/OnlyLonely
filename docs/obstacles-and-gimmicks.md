# 🌟 障害物・ギミック仕様書

## 概要

ゲーム中に登場する障害物とギミックの詳細仕様。  
**風船を持った子供**に対する影響、出現高度、効果、物理挙動などを定義します。  
高度や条件によって異なる要素が配置され、ゲームに戦略性と面白さを追加します。

### プレイヤーキャラクター

- **風船を持った子供**（2D スプライト）
- 風船の浮力で上昇
- 障害物に当たるとダメージや位置変化を受ける

詳細は [キャラクター仕様書](./character-spec.md) を参照。

## 詳細仕様

### 1. 電線

| 項目           | 内容                                          |
| -------------- | --------------------------------------------- |
| **出現高度**   | 低高度（0m ～ 50m）スタート直後               |
| **効果**       | 子供と風船が引っかかって一時停止（1〜2 秒）   |
| **見た目**     | 黒い線、電柱付き                              |
| **物理挙動**   | 衝突時に子供の速度を 0 にし、一定時間後に解放 |
| **サウンド**   | ビヨーンという引っかかる音                    |
| **配置**       | 横方向に複数本配置                            |
| **難易度**     | 低（避けやすい）                              |
| **実装優先度** | 高（スタート直後のお決まり演出）              |

### 2. カラス

| 項目           | 内容                                             |
| -------------- | ------------------------------------------------ |
| **出現高度**   | 低高度（50m ～ 150m）                            |
| **効果**       | 風を送られて下に押し下げられる（高度 -20m 程度） |
| **見た目**     | 黒いカラス、羽ばたくアニメーション               |
| **物理挙動**   | 子供に接触すると下向きの力を加える               |
| **サウンド**   | カーカーという鳴き声、羽ばたき音                 |
| **配置**       | ランダムに飛び回る、または固定位置               |
| **難易度**     | 中（避けにくい）                                 |
| **実装優先度** | 中                                               |

### 3. 凧揚げ

| 項目           | 内容                             |
| -------------- | -------------------------------- |
| **出現高度**   | 低〜中高度（50m ～ 200m）        |
| **効果**       | 透過不可の障害物、引っかかる     |
| **見た目**     | カラフルな凧、糸が下に伸びている |
| **物理挙動**   | 完全障害物、子供が跳ね返る       |
| **サウンド**   | ヒュルルという風切り音           |
| **配置**       | 横方向にゆっくり揺れる           |
| **難易度**     | 中（避けられるが邪魔）           |
| **実装優先度** | 中                               |

## 実装メモ

### 種類別の実装

```swift
enum ObstacleType: String, Codable {
    case powerLine      // 電線
    case crow           // カラス
    case kite           // 凧揚げ
    case cloud          // 雲（松・竹・梅）
    case rocket         // ロケット
    case shootingStar   // 流れ星
    case meteorShower   // 流星群
    case meteorite      // 隕石
    case astronaut      // 宇宙飛行士
}

enum EffectType {
    case freeze         // 一時停止
    case pushDown       // 押し下げる
    case block          // 遮る
    case liftUp         // 持ち上げる
    case damage         // ダメージ
    case visual         // 演出のみ
}
```
