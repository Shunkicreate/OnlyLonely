# 🌟 障害物・ギミック仕様書

## 概要

ゲーム中に登場する障害物とギミックの詳細仕様。  
**風船を持った子供**に対する影響、出現高度、効果、物理挙動などを定義します。  
高度や条件によって異なる要素が配置され、ゲームに戦略性と面白さを追加します。

### プレイヤーキャラクター

- **風船を持った子供**（2D スプライト）
- 風船の浮力で上昇
- 障害物に当たるとダメージや位置変化を受ける

詳細は [キャラクター仕様書](./character-spec.md) を参照。

## 詳細仕様

### 1. 電線

| 項目           | 内容                                          |
| -------------- | --------------------------------------------- |
| **出現高度**   | 低高度（0m ～ 50m）スタート直後               |
| **効果**       | 子供と風船が引っかかって一時停止（1〜2 秒）   |
| **見た目**     | 黒い線、電柱付き                              |
| **物理挙動**   | 衝突時に子供の速度を 0 にし、一定時間後に解放 |
| **サウンド**   | ビヨーン（バネの音）+ ビリビリ（微弱な電気音）|
| **配置**       | 横方向に複数本配置                            |
| **難易度**     | 低（避けやすい）                              |
| **実装優先度** | 高（スタート直後のお決まり演出）              |

#### 衝突時のフィードバック

- **ビジュアル**: 子供がビヨーンと揺れる、電線が波打つアニメーション
- **オーディオ**: ビヨーン（バネの音）+ ビリビリ（微弱な電気音）
- **ハプティクス**: `.medium` タップ（iPhone）
- **iPad**: 衝突地点に星型エフェクト

### 2. カラス

| 項目           | 内容                                             |
| -------------- | ------------------------------------------------ |
| **出現高度**   | 低高度（50m ～ 150m）                            |
| **効果**       | 風を送られて下に押し下げられる（高度 -20m 程度） |
| **見た目**     | 黒いカラス、羽ばたくアニメーション               |
| **物理挙動**   | 子供に接触すると下向きの力を加える               |
| **サウンド**   | カーカー（鳴き声）+ バサバサ（羽ばたき音）       |
| **配置**       | ランダムに飛び回る、または固定位置               |
| **難易度**     | 中（避けにくい）                                 |
| **実装優先度** | 中                                               |

#### 衝突時のフィードバック

- **ビジュアル**: カラスが羽ばたきアニメーション、子供が押し下げられる軌跡エフェクト
- **オーディオ**: カーカー（鳴き声）+ バサバサ（羽ばたき音）
- **ハプティクス**: `.medium` タップ（iPhone）
- **iPad**: 子供の周りに風のパーティクルエフェクト

### 3. 凧揚げ

| 項目           | 内容                             |
| -------------- | -------------------------------- |
| **出現高度**   | 低〜中高度（50m ～ 200m）        |
| **効果**       | 透過不可の障害物、引っかかる     |
| **見た目**     | カラフルな凧、糸が下に伸びている |
| **物理挙動**   | 完全障害物、子供が跳ね返る       |
| **サウンド**   | ヒュルル（風切り音）+ コツッ（軽い衝突音）|
| **配置**       | 横方向にゆっくり揺れる           |
| **難易度**     | 中（避けられるが邪魔）           |
| **実装優先度** | 中                               |

#### 衝突時のフィードバック

- **ビジュアル**: 衝突地点に星型エフェクト、子供が跳ね返る
- **オーディオ**: ヒュルル（風切り音）+ コツッ（軽い衝突音）
- **ハプティクス**: `.medium` タップ（iPhone）
- **iPad**: 凧が少し揺れるアニメーション

### 4. 雲（松・竹・梅）

詳細は [雲システム仕様](./technical-spec.md#雲システム仕様) を参照。

| 種類 | 出現高度 | 効果                         | 難易度 |
| ---- | -------- | ---------------------------- | ------ |
| 松   | 中高度   | 雷ギミック付き、風船が割れる | 低     |
| 竹   | 中高度   | 強い勢いで通過可能           | 中     |
| 梅   | 高高度   | 完全障害物、通り抜け不可     | 高     |

#### 衝突時のフィードバック（雲）

##### 松の雲

- **ビジュアル**: 雲が揺れる、雷の予兆フラッシュ
- **オーディオ**: ボフッ（柔らかい衝突音）+ ゴロゴロ（遠雷）
- **ハプティクス**: `.medium` タップ（iPhone）
- **雷ヒット時**:
  - ビジュアル: 風船が割れる演出、子供が透明度チカチカ（無敵時間）
  - オーディオ: ビリビリッ（電撃音）+ バリバリ（雷鳴）
  - ハプティクス: `.heavy` インパクト + 連続振動（0.3秒）
  - スローモーション演出（0.3倍速、0.2秒間）

##### 竹の雲

- **ビジュアル**: 雲が半透明になり、子供が減速しながら通過
- **オーディオ**: シュッ（風切り音）+ ボソッ（通過音）
- **ハプティクス**: `.light` タップ（iPhone）
- **iPad**: 通過時に雲のパーティクルが少し散る

##### 梅の雲

- **ビジュアル**: 雲が硬く光る、子供が強く跳ね返る、小さな衝撃波エフェクト
- **オーディオ**: ボンッ（硬い衝突音）+ ドォーン（重低音の反響）
- **ハプティクス**: `.heavy` インパクト（iPhone）
- **iPad**: 画面が軽く振動（0.1〜0.2秒）
- **フラッシュエフェクト**: 画面が白く点滅（alpha: 0.3）

### 10. 虹色の綿菓子

| 項目           | 内容                                                                 |
| -------------- | -------------------------------------------------------------------- |
| **出現高度**   | 中〜高高度（200m ～ 550m）                                           |
| **効果**       | 取得すると相手の頭上に虹色の雲が生成され、綿菓子の雨で軽く下降させる |
| **見た目**     | 原宿にあるような大きな虹色の綿菓子（パステルカラーのふわふわテクスチャ） |
| **物理挙動**   | 取得した瞬間に `RainbowCottonCloud` エンティティを相手位置に生成      |
| **サウンド**   | キラキラとしたベル音 + 綿菓子が降る「ふわっ」音                       |
| **持続時間**   | 約 2.0 秒（仮）                                                      |
| **ペナルティ** | 相手高度 -10m（仮）、上昇力も一時的に減衰                             |
| **実装優先度** | 中                                                                     |

#### 挙動

1. プレイヤーが綿菓子アイテムに触れると即取得。
2. 相手プレイヤーの位置に虹色の雲が出現し、綿菓子パーティクルを降らせる。
3. 雲が存在する間、相手は持続的に軽い下降ペナルティを受け、上昇力が弱まる。
4. 効果終了後、雲とパーティクルがフェードアウト。

### 11. シャボン玉セット

| 項目           | 内容                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| **出現高度**   | 中高度（150m ～ 350m）                                                 |
| **効果**       | 取得すると相手側の画面端から吹き棒が出現し、シャボン玉を発射して怯ませる |
| **見た目**     | カラフルなボトルと吹き棒、虹色に輝くシャボン玉                         |
| **物理挙動**   | 吹き棒から 2〜3 個のシャボン玉を連続発射、接触で怯みと軽い下降           |
| **サウンド**   | シャボン玉が膨らむ「ポワン」音 + 割れる「パチン」音                      |
| **持続時間**   | 発射シーケンス 約 3 秒（仮）                                           |
| **ペナルティ** | 相手高度 -5m（仮）、怯み時間 約 0.5 秒                                 |
| **実装優先度** | 中                                                                     |

#### 挙動

1. プレイヤーがシャボン玉セットに触れると、相手側の画面端 (左 or 右) に吹き棒がスライドイン。
2. 0.5 秒の予備動作後、シャボン玉を順番に発射。発射位置や角度は相手の高度を狙うよう調整可能。
3. シャボン玉が相手に当たると一瞬怯むアニメーションと軽い下降ペナルティ。外れた場合は一定時間で自然に消える。
4. 全弾発射後、吹き棒が画面外へ戻り、アイテム効果が終了。

## 実装メモ

### 種類別の実装

```swift
enum ObstacleType: String, Codable {
    case powerLine      // 電線
    case crow           // カラス
    case kite           // 凧揚げ
    case cloud          // 雲（松・竹・梅）
    case rocket         // ロケット
    case shootingStar   // 流れ星
    case meteorShower   // 流星群
    case meteorite      // 隕石
    case cottonCandy    // 虹色の綿菓子
    case bubbleWand     // シャボン玉セット
    case astronaut      // 宇宙飛行士
}

enum EffectType {
    case freeze         // 一時停止
    case pushDown       // 押し下げる
    case block          // 遮る
    case liftUp         // 持ち上げる
    case damage         // ダメージ
    case areaDebuff     // 範囲内ペナルティ（虹色の綿雲）
    case projectile     // 飛び道具（シャボン玉）
    case visual         // 演出のみ
}
```

## 衝突フィードバックまとめ

各障害物との衝突時に、ユーザーに対して以下の 3 つの要素でフィードバックを提供します:

### 1. ビジュアルフィードバック（iPad）
- エフェクト（パーティクル、光、波紋など）
- アニメーション（揺れ、点滅、跳ね返りなど）
- 画面振動（強い衝突時）
- スローモーション演出（重要な衝突時）

### 2. オーディオフィードバック（iPad + iPhone）
- 固有の衝突音（障害物ごとに異なる）
- 空間オーディオ（衝突位置に応じたパンニング）
- 音量変化（衝突の強度に応じて）

### 3. ハプティクスフィードバック（iPhone）
- `.light`: 弱い衝突（竹の雲、流れ星、ロケット）
- `.medium`: 中程度の衝突（電線、カラス、凧揚げ、松の雲、キャラクター衝突）
- `.heavy`: 強い衝突（梅の雲、隕石、雷ヒット）
