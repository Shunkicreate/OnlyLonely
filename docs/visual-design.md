# 🎨 ビジュアル設計書

## 演出仕様

| イベント         | 表現                                                   |
| ---------------- | ------------------------------------------------------ |
| 吹く             | 気流の粒子が発生、風船を持った子供がふわっと光る       |
| 高度上昇         | 背景が明るく、音が軽くなる                             |
| 息を止める       | ゆっくり下降、風船を持った子供が揺れる                 |
| 雲に衝突         | 風船を持った子供が跳ね返る、または減速                 |
| 雷に当たる       | 風船が割れる、風船を持った子供が落下、風船再生成       |
| キャラクター衝突 | 両キャラクターが跳ね返る、衝突エフェクト発生           |
| 障害物衝突       | 衝突箇所に星型エフェクト、画面が軽く振動               |
| 頂上到達         | 小さな鐘の音＋淡い光輪                                 |
| 結果発表         | Winner の風船を持った子供が空の上に消える演出          |
| 虹色の綿菓子獲得 | 相手の頭上に虹色の雲が現れ、綿菓子の粒が柔らかく降り注ぐ |
| シャボン玉攻撃   | 吹き棒が画面端からスライドインし、虹色のシャボン玉が飛ぶ |

## 雲のデザイン

### 雲の種類別デザイン

| 種類 | 色・見た目                   | サイズ | 特徴                     |
| ---- | ---------------------------- | ------ | ------------------------ |
| 松   | 薄いグレー、雷マーク付きの雲 | 小〜中 | 危険なイメージ、電気表現 |
| 竹   | 中間のグレー、ふんわりした雲 | 中     | 通過しやすいイメージ     |
| 梅   | 濃いグレー、重厚感のある雲   | 大     | 通り抜け不可のイメージ   |

### 雲のアニメーション

- ゆっくりと横に揺れる（ループ）
- 松の雲は時々光る（雷の予兆）
- 虹色の綿雲（攻撃時）は淡いグラデーションが脈動し、綿菓子パーティクルを落とす

### 雷のデザイン（松の雲）

- 色: 黄色または白の稲妻
- アニメーション: 雲から下方向に落ちる
- エフェクト: `SKEmitterNode` で電気の粒子を表現
- サウンド: 雷鳴

### 雲衝突時のエフェクト

- 松の雲: 雲が揺れる、通り抜けにくい
- 竹の雲: 風船が減速、雲が少し揺れる
- 梅の雲: 風船が跳ね返る、小さな衝撃波
- 虹色の綿雲: パステルカラーの綿菓子の粒が降り、対象キャラクターの周囲が虹色に染まる
- シャボン玉: 命中すると虹色の泡が弾け、波紋エフェクトが広がる

### 雷ヒット時のエフェクト

- 風船が割れるアニメーション（破裂）
- 稲妻が走る
- 落下エフェクト
- フェードインで新しい風船が生成

### 衝突時のフィードバックエフェクト

#### キャラクター同士の衝突

- **衝突エフェクト**: 衝突地点に白い波紋（`SKEmitterNode`）
- **キャラクター反応**: 両キャラクターが物理的に跳ね返る
- **視覚フィードバック**: 衝突した瞬間に両キャラクターが軽く点滅（0.1秒）
- **パーティクル**: 衝突地点から星型の小さなパーティクルが放射状に飛散

#### 障害物衝突（雲・電線・カラス等）

| 障害物     | ビジュアルフィードバック                                                     |
| ---------- | ---------------------------------------------------------------------------- |
| 電線       | 引っかかった瞬間にキャラクターがビヨーンと揺れる、電線が波打つアニメーション |
| カラス     | カラスが羽ばたきアニメーション、キャラクターが押し下げられる軌跡エフェクト   |
| 凧揚げ     | 衝突地点に星型エフェクト、キャラクターが跳ね返る                             |
| 雲（松）   | 雲が揺れる、雷の予兆フラッシュ                                               |
| 雲（竹）   | 雲が半透明になり、キャラクターが減速しながら通過                             |
| 雲（梅）   | 雲が硬く光る、キャラクターが強く跳ね返る、小さな衝撃波エフェクト             |
| ロケット   | ロケットに引っかかると煙のエフェクトが増加、上昇軌跡が光る                   |
| 流れ星     | 流れ星に触れるとキラキラエフェクト、キャラクターが輝く                       |
| 隕石       | 衝突時に爆発エフェクト、キャラクターが赤く点滅                               |
| 虹色の綿菓子雲 | 虹色の雲が相手を包み、綿菓子の粒が連続して落下、上昇エフェクトが霧散する     |
| シャボン玉     | 泡が命中すると虹色に弾け、キャラクターが少し後退する波紋エフェクト         |

#### 共通の視覚フィードバック

- **画面振動**: 大きな衝突（梅の雲、隕石）では画面全体が軽く振動（0.1〜0.2秒）
- **スローモーション**: 重要な衝突（隕石、雷）では瞬間的にスローモーション演出（0.3倍速、0.2秒間）
- **フラッシュエフェクト**: 衝突の強さに応じて画面が白くフラッシュ（alpha: 0.3〜0.5）
