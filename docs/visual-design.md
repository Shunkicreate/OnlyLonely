# 🎨 ビジュアル設計書

## 演出仕様

| イベント   | 表現                                 |
| ---------- | ------------------------------------ |
| 吹く       | 気流の粒子が発生、風船がふわっと光る |
| 高度上昇   | 背景が明るく、音が軽くなる           |
| 息を止める | ゆっくり下降、風船が揺れる           |
| 頂上到達   | 小さな鐘の音＋淡い光輪               |
| 結果発表   | Winner の風船が空の上に消える演出    |
