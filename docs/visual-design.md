# 🎨 ビジュアル設計書

## 演出仕様

| イベント   | 表現                                 |
| ---------- | ------------------------------------ |
| 吹く       | 気流の粒子が発生、風船がふわっと光る |
| 高度上昇   | 背景が明るく、音が軽くなる           |
| 息を止める | ゆっくり下降、風船が揺れる           |
| 雲に衝突   | 風船が跳ね返る、または減速           |
| 雷に当たる | 風船が割れる、落下、再生成           |
| 頂上到達   | 小さな鐘の音＋淡い光輪               |
| 結果発表   | Winner の風船が空の上に消える演出    |

## 雲のデザイン

### 雲の種類別デザイン

| 種類 | 色・見た目                     | サイズ | 特徴                     |
| ---- | ------------------------------ | ------ | ------------------------ |
| 松   | 濃いグレー、重厚感のある雲     | 大     | 通り抜け不可のイメージ   |
| 竹   | 中間のグレー、ふんわりした雲   | 中     | 柔軟性のあるイメージ     |
| 梅   | 薄暗いグレー、雷マーク付きの雲 | 大〜中 | 危険なイメージ、電気表現 |

### 雲のアニメーション

- ゆっくりと横に揺れる（ループ）
- 梅の雲は時々光る（雷の予兆）

### 雷のデザイン（梅の雲）

- 色: 黄色または白の稲妻
- アニメーション: 雲から下方向に落ちる
- エフェクト: `SKEmitterNode` で電気の粒子を表現
- サウンド: 雷鳴
